# Procedural pass vs artist sculpt

Deep reference for [../SKILL.md](../SKILL.md). This is the honesty boundary of the skill.

## What each method is good for

| Procedural / scripted pass | Artist sculpt (human, manual brush control) |
|---|---|
| Broad landmark placement from measured anatomy | Breast soft tissue: root, poles, fold, lateral wrap, gravity |
| Setup: masks, region groups, locks, guides | Complex abdomen planes and softness |
| Diagnostics: measurements, curvature, symmetry, penetration | Pelvis/glute transitions, glute-ham weight |
| Tiny controlled corrections (low-amplitude, low-frequency, maskable) | Nuanced back: scapulae, erector masses, lumbar/sacral transitions |
| Symmetrize / compare / propagate to LODs / export morphs | Natural asymmetry that reads as a person |
| Deformation validation and QA captures | Final aesthetic judgement and form hierarchy |

Scripts can place and measure forms; they cannot see and judge them the way a sculptor iterates brush strokes under
grazing light. Averaged, symmetric, uniform-amplitude "anatomy" is the typical signature of a procedural pass.

## Honesty rules

1. **Never claim "artist-grade sculpt"** (or ARTIST-GRADE = YES) for geometry generated by scripts, offsets, primitives,
   smoothing, displacement fields or automated morph fitting, however good the numbers look.
2. **State the limitation plainly** when the session has no genuine manual brush control (headless Blender, editor
   Python, GeometryScript): "This is a procedural pass; manual artist sculpting is not available in this session."
3. **Label every result by method**: PROCEDURAL / ARTIST / HYBRID (artist sculpt + scripted QA/propagation). HYBRID
   counts as artist-grade only for the regions a human actually sculpted.
4. **Do not repeat procedural anatomy passes** hoping for artist quality once the procedural ceiling is reached; switch to
   the artist route.
5. **Do not fake visual acceptance** with numeric QA: penetration counts, circumferences and symmetry metrics are
   supporting evidence, not art approval.

## When the artist route is required

- The brief asks for artist-grade / production-final body quality.
- The remaining defects are soft-tissue transitions, gravity, asymmetry or form hierarchy (see table above).
- Two procedural iterations did not improve the visual verdict at matched cameras.
- A region needs non-uniform, judgement-driven shape (breast, glute-ham, abdomen, back).

## Scripting supports the artist

Use scripts for masks, measurement, symmetry, landmark guides, topology/vertex-order safety, before/after comparison,
deformation validation, LOD transfer, morph export and QA. Do not use scripting as a substitute for visual art judgement
when the task requires artist-grade sculpt.

## Artist round-trip package (what to prepare)

1. **Exact source**: the current accepted mesh state (topology, vertex order, UVs, weights, bind skeleton/pose) with a
   pristine locked copy and hashes.
2. **Layered working state**: the accepted base and any procedural layer as locked shape keys/layers; one working layer
   for the artist.
3. **Protection**: masks/locks for protected regions (face identity, head/body seam band, hands/feet if accepted),
   plus warnings when they are touched.
4. **Guides**: landmark markers, symmetry plane, reference views and cameras matching the review protocol, a short
   sculpt guide with the direction (region findings from the review) and amplitude guidance.
5. **Validator**: topology/vertex-count/order unchanged, protected-region deltas zero (or under tolerance), seam
   deltas identical on both sides, amplitude report per region, symmetry report; refuses export on FAIL.
6. **Exporter**: artist delta → the project's morph/corrective format, reproducing the base exactly when untouched.
7. **Post-return plan**: validate, import to an isolated candidate, rebase correctives, propagate LODs, deformation and
   clothing QA, matched BEFORE/AFTER boards, and only then ask for acceptance.

## Reviewing the human-produced sculpt

Run the same [visual review](visual-review.md) as for any body; ARTIST-GRADE = YES only for regions the artist actually
sculpted and that pass the gates. Feedback to the artist uses the professional review language, per region, with
screenshots, and never re-sculpts their work procedurally without being asked.
