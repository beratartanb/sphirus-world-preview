## Anti-hallucination / honesty
- The skill separates procedural or scripted work from a real artist sculpt. Results are labelled PROCEDURAL / ARTIST / HYBRID.
- ARTIST-GRADE is a YES/NO gate that can never be YES for script-only geometry. The profile marks BR_Neutral as ARTIST-GRADE = NO.
- When a session has no manual brush control, the skill says so plainly and prepares the artist round-trip package (source, locks, guides, validator, exporter, post-return plan) instead.
- Numeric QA is supporting evidence only and never grants art acceptance.
