"""V2.24 SHME source patch D: the perceptual follow releases while the VIEW turns (CamFolYawFade, deg/s; 0 = V2.23 law).
Measured (v224t6, fixed 30 FPS): with CamFollowEnabled the screen-x jitter of the mouse-turn run d_jog went 5.3 -> 10.8 and strafing 13 -> 18;
the stored follow offset is world-frame while the soft zone is camera-frame, so a view turn sweeps the offset across the zone edges and
the zone spring answers it. A view turn is the player's own framing: while the camera yaw rate is high the follow offset re-centres on a
critically damped spring (rate CamFolYawW) instead of being re-pushed, weight = clamp(|yaw rate| / CamFolYawFade, 0, 1)."""
import pathlib
V1 = pathlib.Path(__file__).resolve().parents[2] / 'Tools/SHME_V1_20260925'
def patch(fname, old, new, marker):
    p = V1 / fname; t = p.read_bytes().decode('utf8')
    if marker in t: print(fname, marker, 'already'); return
    for nl in ('\n', '\r\n'):
        o = old.replace('\n', nl)
        if t.count(o) == 1: p.write_bytes(t.replace(o, new.replace('\n', nl)).encode('utf8')); print(fname, marker, 'patched'); return
    raise AssertionError((fname, marker))
