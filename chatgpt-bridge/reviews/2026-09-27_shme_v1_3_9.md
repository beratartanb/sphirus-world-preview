## P1 — Sprint 20-30 deg curve: outside-foot slide

- **USER-VISIBLE DEFECT**: on a sustained sprint curve the outside foot slid sideways on every plant.
- **BEFORE**: V1.3.8 gait lateral slip 5.6 cm/plant at 25 deg/s; V1.3.9 baseline (`v139a_curve_*`) outside 2.6 / 3.6 cm
  steady with pops at bucket switches; slalom 13.1 cm lateral.
- **ROOT OWNER**: a STRAIGHT sprint loop carried along a curved capsule path (arc offset + mesh rotation about the capsule)
  - FootPlacement cannot hold a 0.14 s sprint plant (footspeed curve dipped below 60 cm/s for one frame per stance) and
  converted the slide into backward drag.
- **IMPLEMENTATION**: source-level fallback. Six curved sprint loops baked from `A_LB_Sprint_Fwd` (`v139_curve_bake.py`:
  root arc, stance balls pinned at mid-stance, legs re-solved, cyclic swing blend; foot error 0, pinned step 0), one
  database each; SHME curve route in `Update_MotionMatching` (branch on `SHM_CurveActive` before the sprint-loop search,
  tree on `SHM_CurveRate`, one 25 deg/s curvature per side), snapshot steadiness gate + 0.4 s dwell, bucket-lock search
  throttle, curve play rate 0.813, half FootPlacement lock on the curve route; sprint footspeed curves clamped in stance.
- **ASSETS / GRAPHS**: `A_SHM_Sprint_Curve_{R,L}{12,25,40}`, `PSD_SHM_SprintCurve_*` (new); `A_LB_Sprint_Fwd{,Left,Right}`,
  `PSD_LB_SprintLoops`, `ABP_GR_MotionMatchingBase` (curve route, throttle, snapshot).
- **AFTER** (`v139fc_curve_*`, steady 14 s arcs, rendered feet; outside / inside per plant, R / L turn):

## P2 — Directional start stance unification

  prelift stagger up to 75 cm. First V1.3.9 jog vocabulary (AAMS `M_Neutral_Run_Start_*`) = sprint-style dash: trunk
  pitch peak 67 deg, pelvis 69 cm, lift latency 0.65 s (`v139x_jog_0`).
- **ROOT OWNER**: family-4 start route searched only the walk start databases; the AAMS run/sprint starts are authored from

  `SHME/Animations/Starts/Jog/SHM_JogQ_*` (sources untouched) and grouped by measured first-swing foot
  (`v139_jogq_build.py`); gait branch in front of each start search (`install_start_route.py`, `SHM_StartGait`); start

- **ASSETS / GRAPHS**: 17 `SHM_JogQ_*` + `PSD_SHM_JogStartQ_L/R`, `SHM_Sprint_Start_*`, `PSD_SHM_SprintStart_L/R` (new);
